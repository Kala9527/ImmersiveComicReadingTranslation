## Why It Stands Out

- Built for comic readers, not a generic translation demo.
- Screenshot-first presentation so the workflow is visible immediately.
- Configurable OCR and translation models for different usage habits.
- Compact enough to study, fork, and adapt into your own toolchain.

## What It Does

- Captures text from the screen and turns it into readable translation.
- Supports overlay-style interaction while staying inside the reading flow.
- Keeps the setup focused on practical, runnable Android usage.
