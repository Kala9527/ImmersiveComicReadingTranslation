## 功能亮点

- 漫画阅读场景下的 OCR 悬浮翻译。
- 可配置 OCR 模型和翻译模型，适配不同使用习惯。
- 保持本地优先的工作流，便于调试和维护。
- 文档、截图和说明集中在一起，方便快速上手。

## 快速开始

```bash
gradlew.bat assembleDebug
```
